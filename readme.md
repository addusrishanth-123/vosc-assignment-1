# 🎮 Neon X-O Arena

> **Ultimate Tic-Tac-Toe Gaming Experience**

A modern, interactive and responsive **Tic-Tac-Toe game** built using only **HTML, CSS and Vanilla JavaScript**.

This project was developed as part of **VOSC Activity-1 – Prerequisite Activity**.

---

## 🚀 Features

### 🎯 Game Modes

- 🤖 **VS AI** – Play against the computer
- 👥 **2 Players** – Local multiplayer
- 🏆 **Championship** – First player to reach 3 wins
- ⏱️ **Time Attack** – 20 seconds for each player

### 🤖 AI Difficulty

The AI includes multiple difficulty levels:

- 🟢 Easy
- 🟡 Medium
- 🔴 Hard
- ☠️ Impossible

The Impossible mode uses the **Minimax algorithm** to make optimal moves.

---

## 🏆 Gameplay Features

- Correct detection of all **8 winning combinations**
- Winning-cell highlighting
- Animated winning line
- Draw detection
- Round system
- Score tracking
- Win streak tracking
- Time-based gameplay
- Victory result screen
- Rematch option
- Main menu navigation
